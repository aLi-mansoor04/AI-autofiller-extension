# ApplyPilot

ApplyPilot is a Manifest V3 browser extension that helps speed up job applications. It fills common application fields from a profile you control and can use Groq to tailor a resume to a job description.

## Features

- Autofill common contact, education, work, and work-authorization fields.
- Skip fields that already contain a value by default; review filled fields before submitting.
- Extract a job description from the current page or enter it manually.
- Optionally tailor a master resume with Groq and export the result using your browser's print-to-PDF flow.
- Store your profile, resume, and settings in the browser's local extension storage.

AI output is generated by a language model and may be inaccurate. Review every field and resume change before using or submitting it. ApplyPilot does not guarantee that generated content is factual or that a form will be filled correctly.

## Install

There is no build step or package installation.

1. Download or clone this repository and keep the files together in a folder.
2. Open `chrome://extensions` in Chrome or `brave://extensions` in Brave.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the project folder containing `manifest.json`.
5. Pin ApplyPilot from the browser's extensions menu.

After updating the files, reload ApplyPilot from the extensions page. Refresh any job application page that was already open.

## Configure

1. Open ApplyPilot and select **Edit Profile, Master Resume & API Key**.
2. Enter the profile information you want to use. The initial profile and resume are blank.
3. Optionally add a Groq API key and model name to enable AI resume conversion and tailoring. Obtain and manage API keys through [Groq Console](https://console.groq.com/keys).
4. Paste or edit your master resume JSON, then select **Save All Settings Locally**.

Without a Groq key, tailoring runs in local simulation mode and returns the saved resume unchanged; it does not generate AI content.

## Use

- On a job application page, choose **Fill This Application** or press **Alt+Shift+F**. ApplyPilot highlights filled fields and reports skipped or uncertain fields.
- Choose **Extract JD & Tailor Resume** or press **Alt+Shift+T**. Review the extracted job description, edit it if needed, and run tailoring.
- Review the resulting resume, then copy it or open the print dialog to save it as a PDF.

Shortcuts can be changed at `chrome://extensions/shortcuts`. Browser-protected pages (such as the Chrome Web Store and browser settings) do not allow content scripts.

## Privacy and permissions

ApplyPilot does not use an ApplyPilot-operated backend. The extension stores profile, resume, and settings data in `chrome.storage.local` on the browser profile where it is installed. This is local browser storage, not encrypted secret storage; protect access to your browser profile and avoid entering information you do not want stored there.

When a Groq API key is configured and an AI feature is used, ApplyPilot sends the pasted resume text or master resume and the job description to Groq's API for processing. Review Groq's policies before using this feature with personal information. The API key is stored in local extension storage.

The extension requests:

- `storage` to save profile, resume, and settings locally.
- `activeTab` and `scripting` to interact with the current page for autofill and job-description extraction.
- `downloads` for browser download capability.
- Access to `https://api.groq.com/*` for optional AI requests.
- A content script on web pages so the extension can inspect and fill forms when you invoke it.

Autofill is initiated by you; inspect all changes and confirm the contents of any application yourself before submission.

## Project layout

```text
background/   Extension service worker and optional Groq integration
content/      Page form autofill and job-description extraction
options/      Profile, master resume, and settings editor
popup/        Toolbar popup and resume tailoring interface
manifest.json Extension manifest
```

## Compatibility

ApplyPilot targets Chromium-based browsers that support Manifest V3, including Chrome and Brave. There is no automated test suite or build system configured in this repository.
